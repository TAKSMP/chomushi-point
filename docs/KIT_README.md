# ちょうむしポイント アプリ作成キット

このキットには、Claude Codeで新規アプリを実装するための仕様書、画面見本、背景・UI素材、手描き下書きが入っています。

## 使い方

1. `cho-mushi-app-kit/` をClaude Codeで開く作業フォルダーへ展開します。
2. `CLAUDE_CODE_PROMPT.md` の内容をClaude Codeに渡してください。
3. Claude Codeには `README.md` と `assets/`、`reference/` を先に確認してから実装するよう指示しています。

## フォルダー

- `assets/backgrounds/`: アプリ画面背景
- `assets/ui/`: 透明背景の共通UI素材と、加算・減算用ポイントボタン
- `reference/screens/`: ホーム、みんなのポイント、むしさがしの画面見本
- `reference/sketches/`: 元の手描き下書きと初期デザイン参考
- `CLAUDE_CODE_PROMPT.md`: Claude Codeへ渡す実装指示書

## 重要な仕様

- 新規のスマートフォン向けWebアプリ。複数デバイスで家族データを共有。
- 1〜6名でプレイ。ゲーム中は複数プレイヤーを選択し、同じ加減点を各人へ適用。
- 新しいゲームは各参加者0点から開始。終了時の最終ポイントを累計へ加算。
- みんなのポイントのグラフは、完了ゲームの終了ポイントを半月ごとに合算し、横スクロールで閲覧。
- 0点未満にはしない。名前を削除すると、その人のポイントと履歴も削除。
